# Project histories

Completed draft histories for the videos in this repo: every dated block of how a song got from its first look
test to its current draft (drafts, commits, rounds, the artist's notes and what changed). They were moved here
verbatim from Robin's IndieAgent Claude memory on 2026-10-31, because the memory is loaded into every session and
only needs a song's current state and standing rules.

One file per project, named after its folder (`bobwiseman-reform-party.md` for `bobwiseman-reform-party/`). They
live here, not in each project folder, because several of those folders exist only on open draft branches.

Rules for these files:
- Append, don't rewrite. Each block keeps the date it was written.
- No song lyrics (lines quoting sung words stay in the memory, out of git), no tokens or passwords.
- The current state of a song lives in its memory file and the project's NEXT-SESSION.md, not here.
