# Historical animation studies

Source preserved from early animation experiments. These folders are historical
versions, not replacements for the current production projects elsewhere in this
repository.

- `archive/travel-agent-2026-10-07/`: the original study, full-length version,
  successive painted-journey studies, and directing-score generator.
- `travel-agent-2d-planning/proof/`: the later twenty-second 2D proof.
- `all-the-trees-119/`: the earlier alchemical animation and brass-analysis tools.
- `clay-house-study/`: the WebGL clay-house study and vendored renderer.

## Reproduction requirements

This is a source archive. Artist audio, artwork inputs, generated renders, model
weights, and cached analysis outputs are held separately in the external media
archive. Restore the required inputs into the original relative paths before
rendering. They must remain untracked. The input paths are specified by the
individual HTML, renderer, and analysis files.

The `.mjs` renderers require Node.js, Playwright, Chrome, and FFmpeg. Install
Playwright locally with `npm install --no-save playwright`. The 2D proof retains
its own HyperFrames package and configuration files. Python analysis scripts
declare their dependencies through their imports; those include NumPy, SciPy,
SoundFile, librosa, Pillow, and model-specific libraries where applicable.

The revision-8 Travel Agent renderer reuses the revision-7 rendered opening. That
input can be restored from the external archive or rebuilt using the preserved
revision-7 source. The directing-score HTML and JSON can be regenerated by
running `python3 archive/travel-agent-2026-10-07/story-plan/build.py`.

Whitespace defects were normalized, and obsolete absolute dependency paths were adjusted: Playwright uses normal
package resolution, and two analysis scripts resolve the project directory from
their own location. Machine-specific install/commit helper scripts are retained
only in the external archive. Runtime behavior and artistic decisions are
otherwise preserved, including artwork embedded in JavaScript. Original source snapshots and media remain in that archive.

## Validation boundary

The import is checked for JavaScript/Python syntax, JSON parsing, forbidden
media/data paths, and whitespace errors. A successful syntax check does not mean
a historical project can render without restoring its external inputs. No new
video render is claimed by this preservation change.
