# hjeron-dark-blues-storyboard

Plan-only storyboard for Hjeron's "dream of fire" (hjeron_dark_blues, Second Unit). No media, no
lyrics in this repo. `python tools/build.py` renders `frames/` (local) and both storyboards from
`tools/shots.py` and `docs/storyboard.template.md`; read `docs/STORYBOARD.public.md` here, or the
local `docs/STORYBOARD.md` for the version with lyric lines.
