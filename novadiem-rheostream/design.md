# Design: rheoStream, One System You Own

Concept angle: the framework drawn as a set of construction sheets for one building, so the
architecture reads as something you could build and own, not a cloud service.

Built on `kit/` (copied from `tools/blueprint-kit` by `sync.sh`), theme `rheo`. The kit's README
holds the series rules (line, planned style, furniture, easing, bans). This file only records what
this film sets.

## Palette (theme `rheo`, from rheo.stream's DESIGN.md)

| Token | Hex | Use |
|---|---|---|
| bg | `#06181b` | ground |
| bg-raised | `#0a2327` | room interiors, cards |
| line | `#57e0c6` | all line work |
| line-strong | `#83f0dc` | the one emphasised element per plate |
| ink | `#eaf6f3` | statements, labels |
| ink-dim / ink-faint | `#9fc2bd` / `#6e918d` | annotations / planned (dashed) parts |
| accent | `#ff6a55` | one statement phrase per plate (not in the brand; open question) |
| field | `#eaf6f3` with line `#1f7f70` | plate V only, the light drafting sheet |

## Type

- Title and statements: Geist 800, tracking -0.035em. Title 168px; statements 68 to 72px.
- Plate labels: IBM Plex Mono 22px, tracking 0.22em.
- Annotations and node labels: IBM Plex Mono 400/700, 16 to 20px, tracking 0.12em.

## Motifs

- The streamline field (rheo.stream's hero) opens the film and returns as the channels in plate IV.
- The building (plate III) is the film's anchor; plates IV and VII redraw it small.
