# lumenshaders

The loop trick in `loopnoise.js`, `loopnoise.glsl` and `loopnoise.py` (noise sampled at an offset that travels a closed circle, phase 0 = phase 1) comes from `LT()` in `js/shaders.js` of Leonxlnx/lumenshaders, read at commit 3c54400. No file is copied; the notice is kept because the technique and its one line are his. Study: `references/leon-lin/STUDY-lumenshaders.md`.
