Hold while the backing voice goes buh buh buh

Pick a run, press Play, and hold the space bar (or hold the box with the mouse) for as long as you hear buh buh buh. Let go whenever it stops, even for a moment, and hold again when it comes back. Each run plays its own stretch of the song: run 1 from 0:35, run 2 from 1:33, run 3 from 2:50, about 22 seconds each. Keep going past where you think it ends so the last phrase is caught. Picking a run again clears that run's marks and replays it.
